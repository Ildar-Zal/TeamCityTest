# TeamCity Test Automation Framework

Данный проект представляет собой фреймворк автоматизации тестирования для CI/CD платформы **TeamCity**. Основной упор сделан на проверку бизнес-логики через API, а также на валидацию ключевых пользовательских сценариев на уровне UI.

## Что тестируется (Тестовое покрытие)

Фреймворк покрывает основной сквозной пользовательский сценарий (**Main User Flow**):
* **Управление пользователями:** Создание и верификация учетных записей.
* **Конфигурация сборки:** Автоматическое создание проектов и билд-конфигураций (Build Configurations) через API.
* **Запуск пайплайнов:** Инициация и проверка прохождения сборки (Build Run).

> **Архитектурный подход:** Вся основная бизнес-логика и генерация тестовых данных изолированы и тестируются на уровне **API** для обеспечения максимальной скорости и стабильности. Уровень **UI** используется точечно — для проверки финальных действий пользователя в браузере.

## Стек технологий

* **Язык:** Java
* **Базовый фреймворк:** Spring Boot (конфигурация и управление тест-контекстом)
* **Сборщик проектов:** Maven
* **Тестирование API:** REST Assured (взаимодействие со Swagger-спецификацией TeamCity)
* **Браузерная автоматизация:** Selenide / Selenium
* **Инфраструктура:** Docker / Docker Compose / Selenoid
* **CI/CD:** GitHub Actions (Composite Actions)

## Архитектура развертывания стенда и CI/CD

Проект спроектирован для работы исключительно в изолированном CI/CD контуре с динамическим управлением инфраструктурой. Процесс полностью автоматизирован через кастомный шаг пайплайна (описан в `.github/`):

1. **Инициализация БД:** Разворачивается контейнер `Postgres` и скрипт ожидает его полной готовности (`until pg_isready`).
2. **Восстановление состояния (Идемпотентность):** Из защищенного хранилища скачивается актуальный бэкап TeamCity (`tc-backup.zip`). С помощью встроенной утилиты `maintainDB.sh` состояние платформы разворачивается автоматически. Это решает проблему «холодного старта» сервера и исключает этап ручной настройки.
3. **Безопасность и авторизация:** Скрипт пайплайна динамически парсит логи запущенного `teamcity-server`, извлекает временный токен авторизации суперпользователя (`Super user authentication token`) и прокидывает его в тестовый фреймворк.
4. **UI-окружение:** Параллельно поднимаются `teamcity-agent`, `selenoid` и `selenoid-ui` для выполнения браузерных тестов.

*Примечание: В целях безопасности доступы к инфраструктурному бэкапу и секреты авторизации не выложены в публичный репозиторий. Проект представлен для демонстрации архитектуры фреймворка, подходов к проектированию автотестов и автоматизации CI/CD процессов.*
